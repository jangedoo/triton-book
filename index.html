Learning Triton by Rebuilding Modern LLM Kernels

Author

Sanjaya Subedi

About this book. This book was generated by Claude Code, Anthropic’s coding assistant, working from prompts and reviews by the author. Treat it as a Claude-Code-authored work: the prose, code, exercises, and interactive widgets were drafted by the model and curated by a human. If you find mistakes, please open an issue.

This book is for experienced PyTorch developers who want to write the kernels that sit underneath a modern transformer language model. If you have trained or fine-tuned an LLM, profiled it, and felt the wall between “I can write the model” and “I can write the kernel that makes the model fast” — this book is the bridge.

We teach Triton from first principles by rebuilding the operations that show up in real inference and training stacks: fused softmax, RMSNorm, tiled matmul, FlashAttention, RoPE, KV cache reads and writes, dequant matmul, sampling. Every chapter starts from a PyTorch reference, derives the kernel by hand, walks through the shape math, and ends with tests, benchmarks, and exercises. The kernels are not toys — they are the same patterns you find inside production libraries, with the names of the techniques attached so you can read those libraries afterward.

0.1 How the book is structured

The book is organized in Parts:

  • Part 0 — Orientation. Why Triton, how to set up, and the first kernel.
  • Part 1 — Fundamentals. The Triton mental model: programs, blocks, masks, strides, reductions.
  • Part 2 — Basic NN kernels. Softmax, LayerNorm, RMSNorm, activations. The building blocks.
  • Part 3 — Matmul. Tiled, batched, and persistent matmul. The workhorse of every transformer.
  • Part 4 — Attention. The whole attention pipeline, ending in FlashAttention forward, backward, and KV cache.
  • Part 5 — LLM fusion. Fused residual + norm, fused MLP, cross-entropy, sampling.
  • Part 6 — Quantization. Low-precision storage and dequant matmul.
  • Part 7 — Debug, test, profile, optimize. The craft skills you need to ship.
  • Part 8 — Capstone. Package what you wrote into a mini library, swap it into a real model, and codify your own kernel design playbook.

0.2 How to read it

On a first pass, read the chapters in order. The Parts build on each other, and the early fundamentals show up again and again in later kernels. On a second pass, treat the book as a reference: jump to the chapter for the kernel you need, copy the pattern, adapt it.

0.3 A note on the interactive elements

Some chapters include interactive widgets — sliders that show how block sizes tile a tensor, animations that step through the online-softmax accumulator state, plots that compare configurations. These are written as Quarto Observable JS cells and run entirely in your browser. They are there to build intuition; they do not replace running real benchmarks on a real GPU.
